# 🚀 Mihomo Multi v1.2.0 发布说明

**基于 Mihomo (Clash.Meta) 内核与 Tauri v2 构建的轻量级高性能多端口代理监听绑定桌面客户端。**

---

## 💡 本次版本核心更新亮点

v1.2.0 带来了**实时连接监控看板**、**内核级直连分流路由**、**UWP 回环豁免可视化**、**全量订阅一键刷新**等多项重磅新功能与体验优化：

### 1. 📊 新增实时连接监控与详情看板
- **实时监控各端口连接**：新增「实时连接」页面，动态展示当前正在进行的 TCP/UDP 连接会话，支持显示源端口、目标主机、目的端口、传输协议、实时网速与上传/下载流量；
- **智能筛选与快捷断流**：支持按连接目标、端口、规则链快速搜索和状态筛选，支持单连接断开或一键清空全部活跃连接；
- **连接详情弹窗**：点击单条连接可查看完整的网络元数据链路（包含出站代理、规则链追踪、DNS 解析、进程名称等）。

### 2. ⚡ 内核级自定义排除直连路由
- **sub-rules 精确直连分流**：支持对用户自定义排除项（域名、通配符域名、IP、CIDR）生成严格对应的 Mihomo DIRECT 规则，注入到各入站端口的顶层子规则链中；
- **毫秒级热重载**：保存排除规则联动内核配置动态热重载，无需重启内核即可立即生效；
- **稳定分类智能排序**：前后端统一按特殊主机名、逆向域名层级、IPv4 数值升序、IPv6 及特殊标记进行稳定规范排序，阅读与维护更清晰。

### 3. 🪟 Windows UWP 应用回环豁免查看
- **可视化应用列表**：设置页面新增查看 UWP 应用豁免详情弹窗，自动枚举系统中所有 Windows UWP 应用；
- **清晰状态区分**：清晰区分已豁免（Loopback Exempted）与未豁免应用，支持按应用名称与 PackageFamilyName 快捷搜索。

### 4. 🔄 订阅管理支持一键全量刷新
- **批量同步配置**：订阅列表头部新增「全部刷新」操作按钮，多机场或多配置用户无需逐个手动刷新，一键即可并发拉取最新订阅节点并更新索引。

### 5. 🛠️ 软件更新与环境识别体验优化
- **部署形态自动识别**：设置界面更新检查可精确识别当前运行环境属于「便携版 (Portable)」还是「安装版 (Setup)」，提供匹配的分发包指引；
- **更新检查状态持久化**：优化缓存机制，避免重复无效请求 GitHub API 导致触发速率限制。

### 6. 📐 窗口规范与界面排版细节优化
- **窗口尺寸标准化**：抽取全局窗口尺寸常量，统一主窗口默认与最小尺寸为 `1080x680`，托盘呼出与恢复位置保持一致且避免拥挤；
- **侧边栏网速排版防截断**：优化展开态下的实时上传/下载速率布局与字体对齐，彻底消除极端宽长单位下的截断与省略号闪烁。

## 🍏 macOS 首次安装提示“已损坏，无法打开”或“未知开发者”的解决方案

由于本开源项目尚未购买 Apple Developer 开发者付费证书（$99/年），macOS 的 Gatekeeper（门禁系统）会对从网络下载的未公证应用施加 `com.apple.quarantine` 隔离属性，导致系统弹出警告：**“Mihomo Multi 已损坏，打不开。您应该将它移到废纸篓”** 或 **“无法打开，因为无法验证开发者”**。

这并非文件真正损坏，请通过以下任意一种方式即可正常打开运行：

### 方法 1：一键终端命令解除隔离（推荐，最彻底）

将 `Mihomo Multi.app` 拖入 `应用程序 (Applications)` 文件夹后，打开 macOS 的 **终端 (Terminal)**，复制并执行以下命令：

```bash
sudo xattr -rd com.apple.quarantine /Applications/Mihomo\ Multi.app
```
*执行时需输入当前 Mac 用户锁屏密码（输入时终端不显字符，直接按回车即可）。命令完成后即可正常双击启动应用。*

### 方法 2：通过系统设置安全策略允许运行

1. 双击打开应用，弹出无法打开的拦截对话框后，点击 **取消**；
2. 打开系统 **“系统设置” -> “隐私与安全性”**；
3. 向下滚动至 **“安全性”** 区域，会看到提示：“已阻止使用‘Mihomo Multi’，因为来自身份不明的开发者”；
4. 点击旁边的 **“仍要打开”** 按钮，并在随后弹出的确认框中点击 **“打开”** 并输入锁屏密码即可。
