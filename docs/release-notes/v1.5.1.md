# 🚀 Mihomo Multi v1.5.1 发布说明

**基于 Mihomo (Clash.Meta) 内核与 Tauri v2 构建的轻量级高性能多端口代理监听绑定桌面客户端。**

---

## 💡 本次版本核心更新亮点

v1.5.1 带来了**内置无痕 WebView 沙盒链路嗅探**、**分流规则就地编辑与防重校验**、**Switch 黑白高对比组件升级**以及**主页排版自适应优化**等改进：

### 1. 🔍 智能链路嗅探重构：内置无痕 WebView 沙盒隔离采集
- **无痕沙盒隔离窗口**：重构网站全链路关联域名嗅探机制，采用内置无痕 WebView2 沙盒窗口；
- **确定性端口绑定**：沙盒窗口直接绑定目标代理监听端口并按端口隔离数据目录，彻底杜绝系统级网络污染或外部浏览器混杂请求干扰；
- **页面加载状态感知**：实时同步网页加载生命周期（“加载中” / “加载完成”），并自动识别捕获目标网站整条请求链路中的所有关联域名与子域；
- **智能噪音过滤与聚合**：精细化过滤 WebView2 系统遥测与组件更新流量，支持主域名智能收敛与一键追加至分流规则。

### 2. 📝 分流规则就地修改与防重校验
- **规则就地快速编辑**：分流规则列表中支持直接双击/点击就地修改目标匹配项，无需反复删除与新建；
- **规则防重前置拦截**：新增规则重复性校验机制，避免重复录入相同域名，并提供清晰的交互反馈。

### 3. 🎨 界面视觉与基础组件打磨
- **Switch 黑白高对比风格**：重新设计 Switch 开关控件，提供高辨识度的极简黑白对比质感，深度适配明亮与暗黑双主题；
- **紧凑型 Select 组件**：为基础下拉选择器组件下沉支持紧凑尺寸（`size="sm"`），使得全局分流与嗅探控制栏排布更加精致紧凑；
- **主页排版无溢出优化**：修复主页三列网格在部分窗口宽度下意外出现横向滚动条的问题，保持全视窗自适应整洁体验。
