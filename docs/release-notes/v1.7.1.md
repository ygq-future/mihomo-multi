# Mihomo Multi v1.7.1 发布说明

v1.7.1 新增节点 IP 纯净度与地区解锁探测能力，并对节点可用性评分基线与端口卡片徽标交互做了校准和修复。

## 核心更新与改动明细

### 节点 IP 质量与地区解锁探测（新增）

- 新增 CleanIP (sh.cd) 与 IPPure 双源并发探测，交叉验证出口 IP、地理位置、ASN/组织、时区、纯净度评分、网络属性（住宅 / 机房 IDC）与原生 / 广播判定。
- 双源出口 IP 不一致时明确标注结论冲突；单源失败自动降级并保留可用结果；双源同时失败时通过 ipkk.com 纯文本接口回退补齐出口 IP 与地理位置。
- 每个数据源支持独立重试，无需重跑完整探测。
- 新增 AI 与流媒体区域解锁探测：ChatGPT、Claude、Gemini、TikTok、Netflix、YouTube、Disney+、Prime Video、Reddit，区分可用、仅自制剧、仅网页版、不可用与超时失败。
- 解锁探测改为手动触发，打开探测弹窗不再自动发起请求，避免无谓流量与等待。
- 端口视图、代理视图与订阅节点弹窗统一新增 `IP` / `质量` 操作入口（`NodeEgressActions`），探测结果按节点缓存并在会话内复用。

### 可用性分析评分校准

- 吞吐评分基线调整为平均 2 MB/s、峰值 10 MB/s、谷值 200 KB/s 对应 100 分，更贴近实际代理链路表现。
- 延迟满分阈值由 50ms 放宽至 60ms，减少正常跨境链路被过度扣分。
- 权重设置弹窗为每个评分维度标注 100 分目标值，评分构成更直观。

### 界面与交互修复

- 端口卡片 TUN / ENV 徽标改为短标签，完整说明保留在悬浮提示中；卡片头部徽标支持换行，长节点名不再挤压操作区。
- 修正 Badge 类名合并逻辑（twMerge），`outline` 变体不再覆盖自定义配色；调整 ENV / TUN 与 DIRECT 徽标的前景对比度。
- 弹窗支持嵌套层级：`Esc` 仅关闭最顶层弹窗，关闭 IP 质量弹窗时不会连带关闭底层弹窗。
