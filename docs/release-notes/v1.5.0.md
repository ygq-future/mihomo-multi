# 🚀 Mihomo Multi v1.5.0 发布说明

**基于 Mihomo (Clash.Meta) 内核与 Tauri v2 构建的轻量级高性能多端口代理监听绑定桌面客户端。**

---

## 💡 本次版本核心更新亮点

v1.5.0 带来了**全局网站分流规则管理**、**独立目标网站连通性测速**、**运行时网络栈与 DNS 解析优化**、**出站接管互斥守卫强化**以及**顶部操作栏自适应排布**等多项重要改进：

### 1. 🌐 全局网站分流规则管理与层级化路由
- **全局分流规则**：新增全局生效的网站/域名分流规则管理器，无需为每个监听端口逐一配置相同的目标规则；
- **确定性层级路由覆盖**：严格遵循「端口私有分流规则 > 全局分流规则 > 端口主绑定节点」的确定性路由优先级，既保持灵活度又确保多环境隔离的出口确定性；
- **预置主流服务域名**：全面补全 AI 办公、社交媒体、流媒体与开发工具等常见服务的预置域名分类，支持一键快速选用。

### 2. ⚡ 独立目标网站连通性靶向测速
- **独立网站测速探针**：在分流配置弹窗中支持对特定域名规则发起独立实时网络连通性测速，精准衡量分流节点访问目标网站的实际时延；
- **可视化状态联动**：托盘菜单与主界面实时展示当前生效的全局分流规则总数与状态提示。

### 3. 🚀 运行时网络栈与 DNS 解析深度优化
- **DNS 解析与域名嗅探调优**：精细化 Mihomo 运行时配置生成逻辑，优化本地与上游 DNS 链路，规避特定场景下的域名嗅探解析延迟；
- **直通监听路由加速**：针对 `DIRECT` 直连监听端口优化路由转发调度，避免不必要的链式处理。

### 4. 🛡️ 架构重构与出站接管互斥守卫加固
- **系统代理与 TUN 模式单选互斥守卫**：深度重构出站流量接管控制逻辑，前置端口停用/解绑的清理流程，杜绝断网残留与环境不一致；
- **统一运行时同步流水线**：移除历史残留的多层假缝抽象，统一由状态机驱动端口与内核配置的高性能热重载；
- **环境副作用严格隔离**：修复测试环境下触发系统代理与宿主环境变量注册表写操作的边界问题，保障宿主代理环境稳定。

### 5. 🎨 界面排布紧凑化与细节打磨
- **顶部操作栏单行自适应排布**：优化端口管理器顶栏按钮内边距与下拉选择器弹性响应宽度，彻底解决开启局域网共享时的折行问题；
- **监控视图 Header 统一**：补全实时连接监控页的标题与副标题展示，规范全局页面视觉规范。
