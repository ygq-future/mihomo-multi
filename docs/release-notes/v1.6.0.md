# 🚀 Mihomo Multi v1.6.0 发布说明

**基于 Mihomo (Clash.Meta) 内核与 Tauri v2 构建的轻量级高性能多端口代理监听绑定桌面客户端。**

---

## 💡 本次版本核心更新亮点

v1.6.0 带来了**节点出口公网 IP 实时探测**、**终端环境变量代理与系统代理彻底解耦**、**本地配置原生文件选择导入**、**启动自动检查更新控制**以及**节点列表渲染性能优化**等多项重磅特性与稳定性增强：

### 1. 🌐 节点出口公网 IP 实时探测与一键复制
- **出口公网 IP 探测**：在端口列表、节点网格及节点详情弹窗中支持实时探测节点代理出口公网 IP 及地理位置（国家/地区）；
- **快捷复制菜单集成**：端口快捷菜单新增一键复制出口 IP 功能，满足指纹浏览器、自动化爬虫等多环境隔离场景下的出口审计需求；
- **并发与缓存保护**：后端实现轻量并发探针与错误容灾，避免频繁探测触发第三方查询接口限流。

### 2. 💻 终端环境变量代理与系统代理彻底解耦
- **独立单选受控**：将终端环境变量代理（`http_proxy`、`https_proxy`、`all_proxy`、`no_proxy`）从系统代理中完全拆离，两者独立配置、独立开关；
- **多端口灵活调度**：系统代理与终端环境代理可分别绑定不同的监听端口，彻底杜绝开启系统代理时强绑终端环境变量、或关闭终端代理误关系统代理的情况；
- **设置页与快捷操作重构**：设置页面新增终端环境变量代理专用控制面板，支持快捷端口切换与状态指示。

### 3. 📂 本地配置原生文件选择器浏览导入
- **原生文件对话框**：新增本地配置原生文件选择器（基于 Tauri Dialog 插件与原生能力），支持直接在系统资源管理器中浏览并选取 `.yaml` / `.yml` 订阅配置文件；
- **智能回填配置名**：选择文件后自动提取主文件名作为配置名称，并自动回填绝对路径与校验合法性，避免手动输入路径繁琐易错。

### 4. 🔄 启动自动检查更新开关与持久化更新提示
- **启动自检开关**：新增“启动时自动检查更新”独立开关，支持离线或纯内网环境下自主关闭启动自检网络请求；
- **持久化更新标记**：Header 顶栏版本号与侧边栏设置项联动展示未读更新徽标，在不打扰用户正常操作的前提下温和感知新版本。

### 5. ⚡ 界面渲染性能深度优化与依赖对齐
- **细粒度 Selector 状态订阅**：重构 `ProxyGridView` 与 `ProfileNodesModal` 的 Zustand 状态订阅粒度，彻底消除侧边栏折叠/展开时由于无关状态变动引发的大面积组件无谓重渲染；
- **CSS 布局隔离与 GPU 减负**：为大量节点卡片启用 `contain:layout_style` 与 `content-visibility:auto`，精简过渡属性，剔除小卡片密集的模糊滤镜，极大降低合成层渲染开销；
- **Tauri 依赖版本对齐**：升级前端 `@tauri-apps/api` 与 `@tauri-apps/cli` 至 `2.12.x`，消除与 Rust 后端 `tauri` crate 的版本不一致告警。

### 6. 🛡️ 核心机制稳定性与界面交互细节打磨
- **Fallback 策略组即时切换**：复用内核组级并发测速结果，当主节点探测超时（`delay == 0`）时立即触发 `fb-{port}` 策略组切换兜底，不再被动等待下一轮轮询；
- **退出时系统代理归属保护**：退出清理流程中加入活动端口归属校验，开发调试实例仅在当前生效端口属于自身时才执行系统代理清理，防止误清正式应用的系统代理导致断网；
- **下拉浮层防穿透失焦优化**：监听视窗失焦（`blur`）与退出确认弹窗呼出事件，统一主动收起浮动下拉框与滑块浮层，彻底解决跨窗口穿透与重叠遮挡问题。
