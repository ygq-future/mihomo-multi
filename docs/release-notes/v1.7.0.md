# Mihomo Multi v1.7.0 发布说明

v1.7.0 是迄今为止改动面最大的一个版本：新增完整的终端 CLI（`mm`）与本地控制服务，支持订阅级启用/禁用、订阅节点作为链式代理出口，并统一了中英文界面与 CLI 语言、质量门禁与发版流程。

## 核心更新与改动明细

### 全新终端 CLI（`mm`）

- 新增独立可执行文件 `mihomo-multi-cli`，基于主程序本地控制服务（`ctl.json` + Token）与内核 REST API 工作，随安装包分发。
- 覆盖常用操作：`start` / `stop` / `status` / `list` / `enable` / `disable`、`sub list|update`、`node list`、`test node|sub`、`sysproxy`、`tun`、`env`、`ip`、`copy`、`init`、`lang`、`update`。
- `start` 支持开发态 `tauri dev`（HMR）与发布态独立应用进程，支持 `--silent`、`--timeout`、`--no-wait`；`stop` 优雅关闭主程序并等待退出。
- `init` 输出 `pwsh` / `bash` / `zsh` / `cmd` 的 Shell 集成片段，使 `mm env [port]` 能直接修改当前终端会话；自动探测当前 Shell。
- CLI 别名可配置，NSIS 安装器在安装/卸载钩子中自动注册与清理用户 `PATH`；Shell 集成路径通过 `SHGetKnownFolderPath` 正确解析 Windows 文档目录。
- 全局 `--json` 输出便于脚本化；`--no-color` 与 Windows VT 序列启用以保证多段彩色输出在终端、管道与 Windows 控制台一致。
- CLI 变更状态时向界面广播 `ctl-state-changed` 事件，前端界面即时同步。
- `update` 命令支持检查更新、打印发布说明并下载最新发行包，出口代理按节点可用性评分排序。
- `node list` 支持订阅与节点的模糊/子序列过滤、按可用性筛选；跨过滤视图保持全局节点索引一致；列表端点排序稳定。
- 完整的 zh-CN 帮助翻译与 CJK 状态对齐；`env --eval` 将状态信息输出到 stderr，保持 stdout 仅含可直接求值的 Shell 命令。

### 语言与本地化

- 应用界面、托盘菜单与 CLI 语言统一，支持在运行中切换 `zh-CN` / `en-US` 并持久化；CLI 另支持 `MM_LANG` 与 `--lang` 覆盖。

### 订阅与节点管理

- 新增订阅启用/禁用开关：禁用订阅的节点会从运行时配置、节点列表与各视图中排除，并显示状态警告。
- 订阅节点可作为链式代理出口，支持故障转移与候选探测；配置生成、漂移防护与端口路由同步适配。
- 自动更新跳过已禁用的订阅；主订阅禁用时正确上报 fallback 活跃状态。
- 主节点与备用节点延迟测试解耦，避免备用探测干扰主节点延迟判定。

### 可用性分析与系统代理

- 冷启动评分归一化：未观测的 0 B/s 吞吐不再获得 30.0 基线分，连接错误样本缺失时按中性 50.0 计分，避免未使用的节点压过活跃节点。
- 应用启动时自动恢复终端代理环境变量，避免重启后终端代理配置丢失。

### 生命周期与稳定性

- 新增 Windows 与 Unix 终止信号清理处理器，正常退出、Ctrl+C 与系统关闭时统一释放内核、系统代理与 TUN。
- 修复托盘退出可能无法可靠关闭应用的问题。

### 界面与交互

- 代理视图在切换订阅与页面导航时保留地区、协议与搜索过滤条件。
- 单节点测速时保持节点下拉顺序不变。
- 新增端口映射弹窗与代理规则弹窗的细节修正，移除误用的缺失延迟数据依赖。

### 工程与质量

- 新增统一质量门禁 `pnpm quality`（版本一致性、前后端格式、ESLint、tsc、Clippy、前后端测试、前端构建），CI 与 Release 工作流对齐该门禁。
- 新增 `scripts/check-version-parity.mjs`：校验 `package.json`、`Cargo.toml`、`tauri.conf.json`、`APP_VERSION` 四处版本一致，可附带 Tag 校验。
- 全仓应用 Biome 与 rustfmt 格式化，并在 lint 脚本中强制格式检查。
- 新增 `clean:stale` 脚本清理旧的 Cargo 增量编译目录；裁剪开发态 debug 信息、改用默认 rlib 目标以缩短构建时间。
- 新增 `clap` 依赖以支撑 CLI。
