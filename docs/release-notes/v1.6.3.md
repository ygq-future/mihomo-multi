# Mihomo Multi v1.6.3 发布说明

v1.6.3 增强托盘快捷操作，并加入内核更新定期检查与 MRS 规则自动维护。

## 核心更新与改动明细

### 托盘原生多级菜单

- 每个监听端口拥有独立子菜单，展示活动节点、延迟与运行状态，支持直接启用或停用监听。
- 支持探测并复制指定监听端口的出口 IP。
- 支持复制 PowerShell、CMD、Shell / Bash / Zsh 的代理环境变量命令。
- Windows 上运行中的 HTTP / Mixed 监听端口支持直接绑定或取消绑定终端代理。

### 内核更新检查与 MRS 规则维护

- 开启「启动时自动检查更新」后，启动时同时检查软件与 Mihomo 内核更新；常驻运行时每 15 分钟评估一次是否达到 24 小时复检间隔。
- 发现内核新版本后显示通知，可直接跳转设置中的内核更新区域，由用户执行更新。
- 配置加载后自动刷新 MRS 规则，成功后间隔 24 小时再次刷新，每 15 分钟评估一次；规则维护独立于软件更新检查开关，后台执行。
