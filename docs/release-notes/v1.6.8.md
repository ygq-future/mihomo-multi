# Mihomo Multi v1.6.8 发布说明

v1.6.8 重点增强了网络连通性与节点状态判定的准确性，新增出口 IP 缓存过期与刷新失效机制、父宿主进程归并，并对可用性分析、系统代理绕过及多处交互细节进行了打磨。

## 核心更新与改动明细

### 网络连通性与备用节点调度

- 新增宿主网络连通性监控：在宿主机断网或网络波动期间暂停/抑制节点超时判定，避免误报节点不可用。
- 优化备用节点恢复链路：备用组重测恢复时自动刷新 fallback 组状态，并主动探测懒加载的备用节点。

### 出口 IP 缓存与进程历史

- 出口 IP 缓存新增 24 小时 TTL，并在刷新订阅时自动失效，确保节点出口信息及时更新。
- 进程历史支持将子进程解析归并至父宿主应用，并过滤无关噪声进程，提升流量归因可读性。

### 系统代理与可用性分析

- 更新系统代理绕过（Bypass）规则时，自动关闭匹配新绕过规则的活跃连接，使规则变更立即生效。
- 可用性分析评分优先考量有活跃流量的节点，并优化时间线图表的 SVG 排版与展示效果。

### 界面与交互优化

- 重构 `HoverStepSlider` 为紧凑单行胶囊弹出控件，操作更轻量。
- 端口主节点未超时时隐藏健康状态徽章，减少列表视觉干扰；微调协议徽章配色，避免与状态色混淆。
- 修复交互式 Tooltip 在点击或窗口失焦后偶发卡住不消失的问题。
- 精简终端代理开关文案，移除多余的 Windows HKCU 标识。
- 新增中英文双语 README 并更新本地截图。
