# 🚀 Mihomo Multi v1.4.0 发布说明

**基于 Mihomo (Clash.Meta) 内核与 Tauri v2 构建的轻量级高性能多端口代理监听绑定桌面客户端。**

---

## 💡 本次版本核心更新亮点

v1.4.0 带来了**端口级特定网站分流规则与靶向测速**、**首页三段式出站接管开关（直切系统代理/TUN）**、**应用与内核更新自定义代理端口**、**UWP 孤立豁免自动清理**以及**现代化全局主题与设置页交互升级**等多项核心能力：

### 1. 🌐 端口级特定网站分流规则与靶向实时测速
- **精细化网站分流**：在保持端口 1:1 确定性出口的基础上，支持为每个监听端口单独配置特定网站/域名分流规则（可指定走特定代理节点、跟随主节点或 `DIRECT` 直连）；
- **实时靶向测速與延迟同步**：分流规则配置支持针对目标网站发起实时靶向延迟探测，节点选择器实时同步节点测速延迟并按延迟升序排列，方便快速择优。

### 2. 🎛️ 首页三段式出站接管开关与 TUN 专属视觉主题
- **三段式快捷切换**：端口列表首页顶部接入「关闭 / 系统代理 / TUN 模式」三段式滑块开关，无需跳转设置页即可直观切换全局流量接管方式；
- **TUN 专属紫色主题**：开启 TUN 虚拟网卡模式后，相关状态指示与控件自动切换为高辨识度的专属紫色主题，统一全局出站端口数据源。

### 3. 🔄 应用与内核在线更新支持自定义代理端口
- **更新走代理加速**：在「应用设置 -> 软件更新」中新增更新代理端口选择，支持指定任意已启用的本地监听端口作为下载客户端更新包与 Mihomo 内核的代理出口，彻底解决直连 GitHub 缓慢或超时的问题。

### 4. 🧰 UWP 回环豁免自动清理与交互优化
- **自动清理孤立豁免**：刷新 UWP 应用列表时，自动检测并清理系统中已卸载应用残留的孤立 Loopback 豁免记录，保持系统环境整洁，并优化刷新按钮旋转动画反馈。

### 5. 🎨 全局主题美化、弹窗重构与体验细节打磨
- **现代视觉与弹窗布局**：重构模态框（Modal）布局与全局明暗主题配色体系，提升卡片层次感与视觉一致性；
- **设置页导航与滚动记忆**：新增设置页滚动位置记忆与侧边栏分类快捷定位能力，提升长配置页面的操作效率；
- **冷启动与开发隔离优化**：优化客户端冷启动时内核状态同步与端口卡片警告判定时序；支持开发模式实例隔离与全生命周期进程守护。
