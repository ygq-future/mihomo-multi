# Mihomo Multi v1.6.6 发布说明

v1.6.6 为端口列表加入主备节点一键交换与端口进程记录，订阅卡片开始展示剩余流量与到期信息，并修复了端口列表加载时卡片空白与窗口重建尺寸不一致的问题。

## 核心更新与改动明细

### 端口主备节点交换

- 端口卡片新增一键交换主备节点按钮；也可直接拖动备用节点到主节点位置完成交换。
- 交换前校验目标节点是否已被其他端口绑定为主节点，冲突时给出明确提示并拒绝交换。
- 前端采用乐观更新：交换操作立即反映在界面上，后端失败时自动回滚并提示原因。

### 订阅流量与到期信息

- 解析订阅响应头 `Subscription-Userinfo` 以及本地订阅 YAML 中的流量伪节点，提取已用流量、套餐总量、到期时间与流量重置周期。
- 订阅信息随 `ProfileItem.subscriptionInfo` 持久化；启动时对缺少信息的订阅自动回填，旧数据无需重新导入。
- 订阅卡片展示剩余流量百分比进度条与到期状态（长期有效、剩余天数、已过期），并按剩余比例分级着色。
- 端口监听卡片复用同一套订阅徽标：悬停可查看套餐总量、已用流量、剩余流量、到期时间与节点数量。

### 端口进程记录

- Mihomo 内核启用 `find-process-mode: always`，定时采样活跃连接，按端口归集经过的本机应用进程。
- 端口卡片新增「端口进程记录」入口，展示当前活跃与历史应用、进程路径、图标、命中次数与最近使用时间，每个端口保留最近 50 条记录。
- Windows 可执行文件图标在后台线程提取并缓存至 `icon_cache.json`（最多 2048 个，单图标 96KB 上限），打开记录弹窗时无需等待图标加载。
- 删除端口前会提示曾通过或正在使用该端口的应用，避免误删导致应用断网；记录弹窗支持手动刷新与清空。

### 加载与体验修复

- 端口列表加载时先提交端口映射与占用端口，漂移检测与兜底探测在后台异步进行，卡片不再长时间空白。
- 新增端口列表骨架屏与内联加载失败重试状态，加载反馈覆盖简体中文与 English。
- 主窗口默认与最小高度调整为 690；窗口重建时直接读取 Tauri 配置中的尺寸，移除 Rust 侧重复定义的宽高常量，使配置文件成为唯一来源。
