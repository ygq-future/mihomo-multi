# 🚀 Mihomo Multi v1.3.0 发布说明

**基于 Mihomo (Clash.Meta) 内核与 Tauri v2 构建的轻量级高性能多端口代理监听绑定桌面客户端。**

---

## 💡 本次版本核心更新亮点

v1.3.0 带来了**受控 TUN 模式（虚拟网卡）**、**管理员提权引导**、**Windows 开机自启修复**、**托盘防抖优化**等多项重磅功能与稳定性改进：

### 1. 🛡️ Windows 受控 TUN 虚拟网卡模式
- **端口绑定与确定性出口**：TUN 虚拟网卡模式作为受控辅助特性，严格绑定一个已启用的端口映射作为唯一网络出口，继承该端口的节点配置与分流规则，确保全局网络流量与多环境隔离保持确定性；
- **专属网卡命名防冲突**：显式指定 TUN 虚拟网卡设备名称为 `Mihomo-Multi`，避免与其他默认使用 `Meta` 的客户端产生设备命名与句柄冲突；
- **高性能用户态协议栈**：采用 `gvisor` 协议栈并开启 `auto-route` 与 `dns-hijack`，提供稳定隔离的全局流量代理与 DNS 劫持防护；
- **生命周期安全与防断网红线**：TUN 模式与系统代理全局单选互斥；当绑定的端口停用、内核停止或客户端退出时，无条件随内核进程一并释放虚拟网卡，杜绝网络残留导致断网。

### 2. ⚡ UAC 管理员提权检测与平滑重启
- **智能提权检测**：自动检测当前进程是否拥有创建虚拟网卡所需的 Windows 管理员权限；
- **一键平滑提权**：在设置界面提供「以管理员身份重启」引导，提权拉起新进程时携带原进程 PID 实现无缝接管与安静切换。

### 3. 🔧 Windows 开机自启状态判定与修复
- **清理注册表静默禁用项**：联动检查并清理 Windows 注册表 `StartupApproved\Run` 中的静默禁用状态，彻底解决在任务管理器或第三方管家中曾被禁用导致自启动开关状态失真的缺陷。

### 4. 🪟 系统托盘交互与防抖优化
- **双击竞争与闪退保护**：优化系统托盘图标点击防抖与主窗口显隐/聚焦判定逻辑，彻底杜绝快速连击或无意识双击导致主窗口闪退的问题。

### 5. 🎨 界面排版与视觉细节优化
- **连接筛选栏自适应**：优化连接详情页筛选控制栏在默认窗口宽度下的单行展示与自适应间距；
- **订阅卡片三列排版**：优化订阅卡片网格布局，在标准窗口尺寸下呈现更舒适的三列紧凑排版。
