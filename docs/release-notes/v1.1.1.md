# 🚀 Mihomo Multi v1.1.1 发布说明

**基于 Mihomo (Clash.Meta) 内核与 Tauri v2 构建的轻量级高性能多端口代理监听绑定桌面客户端。**

---

## 💡 本次版本核心更新亮点

v1.1.1 专注于**极轻后台内存优化、窗口呈现平滑度升级、端口节点交互增强与界面排版精细化打磨**：

### 1. ⚡ 极轻后台驻留与极致资源调优 (Ultra-low Resource Footprint)
- **支持轻量常驻模式**：新增窗口关闭时释放 WebView 渲染进程机制，常驻托盘时仅保留超轻量 Rust 核心服务，将后台内存占用压缩至极限；再次点击托盘即可毫秒级重建窗口；
- **后台智能休眠**：当应用最小化或处于后台隐藏状态时，自动挂起前端轮询与实时流量 WebSocket，杜绝无意义的 CPU 唤醒与能耗浪费；
- **消除全屏冗余重渲染**：将高频定时器（Uptime 运行时间、实时上下行速率）全量下沉封装为独立叶子组件，避免驱动顶栏及页面大面积无意义重绘；
- **生命周期资源隔离**：引入统一的 `EventScope` 机制管理事件监听器生命周期，彻底杜绝前端事件监听器潜在的内存泄露风险。

### 2. 🎨 原生深色防白闪与窗口平滑呈现 (Zero-Flash Window Polish)
- **彻底消除启动与唤醒深色白闪**：采用跨平台原生画布颜色注入与预染色机制，在系统深色模式下，无论应用冷启动、热启动还是从托盘呼出，均无任何短暂白色闪烁；
- **双层 rAF 严格对齐渲染管线**：结合多主题自适应检测与双层 `requestAnimationFrame` 同步等待机制，确保 WebView 完成真实像素绘制后再呈现窗口，视觉过渡流畅如丝。

### 3. 🎯 端口映射配置与节点优选体验增强 (Port & Proxy Experience)
- **备用节点自动按延迟升序排序**：创建与编辑端口弹窗中，备用节点下拉选择器支持按真实测速延迟由低到高自动排序，快速挑选优质低延迟节点更加直观便捷；
- **系统代理配置常态化展示**：优化系统代理关联端口的展示逻辑与联动同步，进一步消除多阶段步进控制器的抖动与样式跳变；
- **卡片样式与背景层叠去重**：全面清理端口映射卡片在各状态分支下的冗余背景类与样式冲突，禁用卡片样式更具视觉质感。

### 4. 💎 界面排版、协议徽章与文案精细化打磨 (UI Refinement)
- **节点徽章排版防溢出**：重构节点卡片测速结果徽章排版，优化长协议名称简写规则，防止在不同屏幕缩放下挤占操作按钮或发生换行折叠；
- **界面与设置文案降噪**：全面清洗设置项与弹窗中的冗余修饰性文案，明确惰性健康检查的生效边界，优化开关间距并强化排除项的卡片背景质感；
- **真实版本动态渲染**：设置页面“关于”卡片优先联动底层读取当前客户端实际运行版本，保持版本信息精确可信。

### 5. 🛠️ 品牌统合与自动化工程化升级 (Branding & Engineering)
- **全链路品牌统一定名**：项目全链路（代码、托盘提示、产品文档、领域模型）正式统一规范定名为 **Mihomo Multi**；
- **一键自动化多架构打包**：引入自动化构建脚本，支持单命令自动生成各平台安装包与免安装 Portable 绿色便携包，并自动计算全量分发包的 SHA-256 校验和。

## 🍏 macOS 首次安装提示“已损坏，无法打开”或“未知开发者”的解决方案

由于本开源项目尚未购买 Apple Developer 开发者付费证书（$99/年），macOS 的 Gatekeeper（门禁系统）会对从网络下载的未公证应用施加 `com.apple.quarantine` 隔离属性，导致系统弹出警告：**“Mihomo Multi 已损坏，打不开。您应该将它移到废纸篓”** 或 **“无法打开，因为无法验证开发者”**。

这并非文件真正损坏，请通过以下任意一种方式即可正常打开运行：

### 方法 1：一键终端命令解除隔离（推荐，最彻底）

将 `Mihomo Multi.app` 拖入 `应用程序 (Applications)` 文件夹后，打开 macOS 的 **终端 (Terminal)**，复制并执行以下命令：

```bash
sudo xattr -rd com.apple.quarantine /Applications/Mihomo\ Multi.app
```
*执行时需输入当前 Mac 用户锁屏密码（输入时终端不显字符，直接按回车即可）。命令完成后即可正常双击启动应用。*

### 方法 2：通过系统设置安全策略允许运行

1. 双击打开应用，弹出无法打开的拦截对话框后，点击 **取消**；
2. 打开系统 **“系统设置” -> “隐私与安全性”**；
3. 向下滚动至 **“安全性”** 区域，会看到提示：“已阻止使用‘Mihomo Multi’，因为来自身份不明的开发者”；
4. 点击旁边的 **“仍要打开”** 按钮，并在随后弹出的确认框中点击 **“打开”** 并输入锁屏密码即可。
