# Mihomo Multi v1.6.7 发布说明

v1.6.7 新增节点可用性分析面板与端口卡片拖拽换位，扩展区域识别至 55+ 国家/地区，并对内核启停、磁盘写入与前端轮询链路做了系统性的稳定性与性能加固。

## 核心更新与改动明细

### 节点可用性分析面板

- 新增「可用性分析」视图：后端 `node_analytics` 复用延迟探测、内核日志与 `/connections` 快照，不额外发起探测。
- 仅统计已绑定监听端口的节点（主节点与备用节点，名称自动归一化），聚焦真正影响出口的节点。
- 支持可配置的 7 维加权可用性评分：超时次数、超时总时长、连接错误次数、活跃平均 / 最大 / 最小速度、延迟与抖动。
- 30 天逐小时数据持久化，原生 SVG 雷达图与时间线图展示趋势，无需第三方图表依赖。
- 明细表支持排序与质量分级着色（成功率、超时 / 错误计数、延迟、抖动），权重配置支持草稿态预览与恢复默认。

### 区域识别与节点搜索

- 区域规则扩展至 55+ 国家/地区（新增 AR、UA、MY、MO 等），支持 emoji 旗帜解码与短 ASCII 代码的词边界匹配，避免误判。
- 新增 MO / AR / UA / MY SVG 旗帜，未内置旗帜时回退为 2 位 ISO 徽章。
- 下拉选择器支持隐藏关键词搜索：可直接输入 `jp`、`hk`、`us`、`sg` 等区域缩写筛选节点，已接入新增端口、端口规则与代理网格。
- 端口编辑器优先展示当前所选节点所属区域，减少跨区域误选。

### 端口卡片拖拽换位

- 端口卡片支持指针拖拽换位（Pointer Capture），带列表边界约束、边缘自动滚动与 ≥1/3 重叠命中判定。
- 交换由后端原子命令完成，运行时同步更新路由；被直接端口占用的卡片受保护，避免无效交换。
- 新增主题自适应的拖拽落点光环、交换徽标与浮动释放提示，界面文案覆盖简体中文与 English。

### 订阅与延迟探测

- 监听端口提示卡支持直接刷新订阅，无需跳转订阅页面。
- 端口延迟以内核历史延迟为准，后台健康检查可实时反映到界面；首次由可达转为超时时并发重测最多 3 个内置 URL，单次超时统一约束，降低误判。
- 批量延迟写盘节流为 60 秒，内存缓存保持实时更新。

### 稳定性加固

- 引入生命周期锁，内核启动 / 停止 / 重启不再阻塞状态查询；消除配置读写锁跨引擎调用的自死锁。
- 文件写入统一走原子替换（Windows 使用 `MoveFileExW`），覆盖 `runtime.yaml`、退出延迟快照与内核更新备份 / 回滚。
- 阻塞的 OS / 子进程 / 引擎调用迁移至 `spawn_blocking`，避免占用异步运行时。
- 修复批量延迟探测取消竞态、状态查询运行时长差值异常、分析面板轮询覆盖草稿权重、更新检查定时器饥饿、流量嗅探面板卸载残留与设置页字段同步等问题。
- 修复切换标签后设置页滚动位置丢失。

### 性能优化

- 节点分析、进程历史与图标缓存改为 90 秒后台落盘，并周期性清理闲置节点，脱离 2 秒采样与日志热路径。
- 内核日志管道引入 `BufWriter` 与日期缓存，连接错误解析改为零分配预过滤；图标缓存改为 10% 淘汰而非整体清空。
- 托盘悬停提示直接读取内存缓存，杜绝高频 HTTP 请求。
- 前端替换为 `useShallow` 选择器、共享窗口可见性监听、轮询在途保护与行级 `content-visibility`，非活跃设置页不再挂载。
- 发布构建启用 thin LTO、`codegen-units = 1`、`strip = true` 与 `opt-level = 3`。
