# Mihomo Multi v1.6.5 发布说明

v1.6.5 完成界面与托盘的双语国际化（简体中文 / English），并为节点、端口与住宅出口选择框加入即时延迟测速，修复代理页地区筛选栏的布局问题。

## 核心更新与改动明细

### 界面语言国际化

- 新增类型安全的 i18n 词典与翻译层，覆盖简体中文（`zh-CN`）与英语（`en-US`）；设置中的「外观」区域新增「界面语言」选项：跟随系统 / 简体中文 / English。
- 语言选择持久化保存；选择「跟随系统」时按系统语言自动切换，系统语言变化即时生效；简体中文以外（含繁体中文）统一回退英语。
- 全界面完成本地化：侧边栏、顶栏、流量组件、端口监听视图及全部端口弹窗（新增端口、端口规则、流量嗅探、直连端口编辑、快捷复制）、代理页、订阅管理、连接页、设置页与全局提示。
- 端口规则的预设服务（AI 大模型、社交通讯、开发工具、流媒体、游戏平台等）按稳定 id 显示本地化名称与描述，切换语言不会改变已保存规则中的规范化名称。
- 托盘菜单、托盘提示与后端错误信息跟随界面语言；轻量模式静默启动时保留隐藏 webview 最多 5 秒用于同步托盘语言，同步完成或超时后照常销毁，不弹出窗口。

### 代理选择器延迟测速

- 节点、关联端口与住宅出口下拉选择框支持点击选项右侧按钮单独测速，也可点击下拉头部的仪表按钮对当前筛选结果批量测速。
- 测速期间显示加载状态并阻止重复触发；结果直接显示在选项右侧，按延迟分级着色，住宅出口测速使用当前选择的上游节点。
- 新增通用 `SpeedSelect` 组件，基于 `Select` 的选项操作与尾部插槽扩展实现，保持选择、搜索与键盘操作行为一致。

### 修复与体验

- 修复代理页地区筛选栏「全部」选项与地区按钮层级错乱导致的布局偏移，筛选栏在调整后保持稳定排版。
